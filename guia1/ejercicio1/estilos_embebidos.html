Estilos embebidos en las etiquetas HTML: la fórmula de Heisenberg

Usar estilos CSS embebidos en las etiquetas HTML es el peor y el menos utilizado de los métodos para agregar reglas de estilo. Es como cocinar sin receta: funciona una vez, pero nadie puede repetir el resultado. No es nada recomendable por la dificultad que implica realizar un cambio a posteriori.

Esta forma de incluir CSS directamente en los elementos HTML solamente se utiliza en determinadas situaciones en las que se debe incluir un estilo muy específico para un solo elemento concreto, igual que Walter White usaba una sola fórmula con una pureza muy específica.

Para insertar un estilo CSS en un elemento se utiliza la propiedad style de HTML, que en ningún momento se debe confundir con la etiqueta <style> que se introduce en la cabecera del documento.
